01 / BJJ

Brazilian Jiu-Jitsu

El BJJ se basa en controlar al rival, mejorar la posición y buscar una finalización utilizando técnica y estrategia.

Posición

Guardia

Aprende a controlar desde la espalda utilizando las piernas, la cadera y los agarres.

Control

Side Control

Una posición dominante donde controlas el torso del rival y limitas sus movimientos.

Dominante

Mount

Una posición superior desde donde puedes controlar y atacar brazos o cuello.

02 / TÉCNICAS

Técnicas fundamentales

Aprende el objetivo de cada técnica, sus pasos y los errores más habituales.

Sumisión

Armbar

Palanca sobre el codo del rival.

  1. Controla el brazo.
  2. Coloca la pierna sobre el hombro.
  3. Mantén la cadera cerca.
  4. Extiende de forma controlada.
Error común: Perder el control del hombro del rival.
Estrangulación

Rear Naked Choke

Una de las finalizaciones más efectivas desde el control de espalda.

  1. Asegura la espalda.
  2. Controla la cabeza.
  3. Coloca el brazo alrededor del cuello.
  4. Ajusta antes de finalizar.
Error común: Buscar la sumisión antes de asegurar la posición.
Estrangulación

Guillotine

Ataque al cuello muy utilizado contra entradas de derribo.

  1. Controla la cabeza.
  2. Coloca el brazo alrededor del cuello.
  3. Cierra el agarre.
  4. Controla la posición.
Error común: Utilizar solo los brazos.
Guardia

Triangle

Estrangulación utilizando las piernas para controlar cuello y brazo.

  1. Controla la postura.
  2. Coloca una pierna sobre el cuello.
  3. Cierra la figura.
  4. Crea el ángulo correcto.
Error común: No crear suficiente ángulo.
